# Лабораторная работа 3: CI/CD для статического сайта в SourceCraft


## Цели

1. Освоить настройку автоматического развертывания статического сайта, построенного на MkDocs.
2. Изучить публикацию сайта на платформе SourceCraft.
3. Познакомиться с базовыми принципами CI/CD для автоматической сборки и публикации статического сайта.

## Задачи

В рамках лабораторной работы требовалось:

* реализовать автоматическое развертывание статического сайта на MkDocs с использованием SourceCraft;
* настроить автоматическую сборку сайта через CI/CD;
* подготовить структуру проекта и необходимые конфигурационные файлы;
* опубликовать сайт и проверить его доступность через браузер.

## Ход работы

### 1. Подготовка проекта

Для выполнения лабораторной работы был создан новый репозиторий `lab3-sourcecraft`.

В репозитории была подготовлена структура проекта:

```text
lab3-sourcecraft/
├── .sourcecraft/
│   ├── ci.yaml
│   └── sites.yaml
├── src/
│   ├── mkdocs.yml
│   └── docs/
│       └── index.md
├── requirements.txt
└── README.md
```

Файл `requirements.txt` содержит список зависимостей:

```text
mkdocs
mkdocs-material
```

### 2. Настройка MkDocs

Для генерации статического сайта использовался MkDocs с темой Material.

Файл `src/mkdocs.yml`:

```yaml
site_name: Lab 3 CI/CD

theme:
  name: material

nav:
  - Главная: index.md
```

Главная страница сайта была создана в файле `src/docs/index.md`.

### 3. Настройка SourceCraft Sites

Для публикации сайта был создан файл `.sourcecraft/sites.yaml`:

```yaml
site:
  root: docs
  ref: release
```

Данный файл указывает SourceCraft, что опубликованный сайт должен браться из директории `docs` ветки `release`.

### 4. Настройка CI/CD

Для автоматической сборки сайта был создан файл `.sourcecraft/ci.yaml`.

В конфигурации определён workflow, который выполняет следующие действия:

1. Устанавливает необходимые зависимости.
2. Устанавливает MkDocs и тему Material.
3. Выполняет сборку сайта.
4. Публикует собранные файлы в ветку `release`.

После исправления ошибок конфигурации SourceCraft успешно принял настройки CI/CD.

### 5. Публикация сайта

После добавления всех необходимых файлов был выполнен автоматический запуск процесса сборки.

В результате SourceCraft успешно собрал сайт и опубликовал его через сервис SourceCraft Sites.

Сайт стал доступен по адресу:

https://mamamia2282006.sourcecraft.site/lab3-sourcecraft/
